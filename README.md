# Natalidad y Violencia en Guatemala
Proyecto 3 - Mineria de Datos

Este repositorio contiene el código y los datos para el análisis y modelado predictivo de la relación entre la violencia intrafamiliar (VIF) y la natalidad en Guatemala durante el periodo 2009–2021. El objetivo final es comprender y cuantificar cómo la violencia intrafamiliar impacta la natalidad, aportando una herramienta cuantitativa novedosa para investigaciones sociales y políticas públicas en Guatemala.

## Data 

En el archivo “AnalisisExplratorio” se puede encontrar: 

- Archivos de recolección y limpieza de datos .py
- Archivos de Análisis Exploratorios .ipynb
- Archivos de data “raw” .xls
- Archvios de data "nat” y “violencia” .csv
- Archivos de union de “.csv: .py 

En el archivo "PruebasModelos”:

- Archivo de cálculo de métricas .py
- Archivo de LSTM .py
- Archivo de generación de pipelines .py
- Archivos de cada modelo implementado .ipynb 

Afuera de ambos, se puede encontrar el archivo "DataFinal.csv” donde se encuentra la data utilizada para la realización de los modelos.  

## Funcionamiento 

Todos los archivos .ipynb tienen las importaciones correspondientes por lo que no es necesario realizar ningún cambio para su correcto funcionamiento.  

(El proyecto fue realizado en 2025, por lo que actualizaciones de librerias pueden afectar el correcto funcionamiento.)
